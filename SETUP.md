## 🎯 How to Use Each Feature

### **Submitting a Service Request (Citizen)**
1. Login with citizen credentials
2. Click "Submit New Service Request" button
3. Select service type from dropdown
4. Set priority level
5. Enter detailed description (min 10 characters)
6. Optionally attach a file
7. Agree to terms
8. Click "Submit Request"
9. See success notification and updated dashboard

### **Managing Users (Admin)**
1. Login with admin credentials
2. Click "Manage Users" in sidebar
3. Use search bar and filters to find users
4. Click "Add New User" to create user
5. Click "Edit" button to modify user
6. Click "Delete" button to remove user
7. Table updates automatically

### **Processing Requests (Admin)**
1. In admin dashboard
2. Click "Service Requests" in sidebar
3. Use filters to find specific requests
4. Click "Update" button on any request
5. Change status (Pending → Approved → Completed/Rejected)
6. Add comments if needed
7. Click "Update Status"
8. Request status updates in table

### **Viewing Reports (Admin)**
1. Click "Reports" in admin sidebar
2. View pre-calculated statistics
3. Reports include:
   - User statistics
   - Service request statistics
   - System performance metrics
   - Service type distribution
4. Each report has "Download Report" button (simulated)

## 🐛 Troubleshooting

### **JavaScript Errors**
- Check browser console (F12)
- Ensure JavaScript is enabled
- Clear cache and reload
- Check file paths in links

### **Styles Not Loading**
- Verify `src/style.css` path is correct
- Check for CSS syntax errors
- Clear browser cache
- Try hard refresh (Ctrl+Shift+R)

### **Forms Not Submitting**
- Check browser console for errors
- Verify all required fields are filled
- Check JavaScript is enabled
- Ensure form validation passes

### **Local Storage Issues**
- Check if localStorage is enabled
- Clear localStorage if data corrupted
- Try incognito/private mode

### **Mobile Issues**
- Ensure viewport meta tag is present
- Check mobile breakpoints in CSS
- Test touch interactions
- Verify button sizes (44px minimum)
